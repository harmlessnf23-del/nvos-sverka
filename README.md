# Сверка НВОС

Веб-сервис для сверки документов по объектам, оказывающим негативное воздействие на окружающую среду (НВОС):
декларации о плате (ДПНВОС), реестра объектов НВОС (ОНВОС) и декларации о воздействии на окружающую среду (ДВОС).

Работает целиком в браузере: файлы Excel никуда не отправляются, сервер не нужен. Большие выгрузки
(сотни тысяч строк, ~100 МБ) читаются потоково.

## Как пользоваться

1. Откройте `index.html` в браузере (или страницу GitHub Pages).
2. Слева выберите вид воздействия (выбросы / сбросы), категорию объекта и отчётный год.
3. Перетащите выгрузки Excel в карточки документов — столбцы сопоставятся автоматически, при необходимости их можно поправить.
4. Нажмите «Запустить проверку» и скачайте отчёт `.xlsx`.

## Проверки II категории

Ключ сопоставления — код объекта НВОС + ИНН.

| Код | Проверка |
|---|---|
| II-01 | По объекту реестра подана ДПНВОС (номер отчёта); если нет — проверяется дата исключения из реестра |
| II-02 | Объект из ДПНВОС / ДВОС найден в реестре ОНВОС по коду и ИНН |
| II-03 | ДВОС подана и действует в отчётном году (7 лет с даты подачи) |
| II-04 | Коды загрязняющих веществ совпадают в ДПНВОС, ОНВОС и ДВОС; показывается, где вещества нет |
| II-05 | Масса вещества совпадает: ДПНВОС (W) = ОНВОС (AE) = ДВОС (W); тип расхождения — сверхлимит / меньше реестра / расхождение с ДВОС |

Категории III и IV — шаблонные правила, I категория — в разработке.

## Требования

Современный браузер: Chrome / Edge / Яндекс Браузер 103+, Firefox 113+, Safari 16.4+.
Библиотека [SheetJS](https://sheetjs.com) и шрифты загружаются с CDN.
